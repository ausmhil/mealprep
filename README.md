# 🥗 Weekly Meal Prep Calculator (v4.1 ✨)

A lightweight, responsive, single-page web application for planning weekly meals, calculating family portion scaling, and generating dynamic grocery lists.

---

## ✨ Features

- **👨‍👩‍👧 Family Portion Scaling:** Dynamically scales ingredients and recipes based on household size (1 person, 2 people, or 3 people with custom adult/toddler weighted calculations).
- **📋 Interactive Recipe Manager:** View, filter, and add custom recipes with macro calculations (Calories, Protein, Carbs, Fats).
- **📅 Weekly Meal Schedule:** Plan out meals across the entire week (Breakfast, Lunch, Snacks, Dinner) with real-time calorie tracking.
- **🛒 Dynamic Grocery Checklist:** Automatically aggregated ingredients with categorized check-off lists and shopping progress tracking.
- **🚀 Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript.

---

## 💻 Usage

Simply open `index.html` in any web browser, or access the live deployment hosted via GitHub Pages.
